In Eclipse:

JDBCMovieProject

Right Click
src → New → Class

Class Name:

MovieJDBC

public static void main(String[] args)

Finish

JDBCMovieProject

Build Path → Configure Build Path

Add External JARs

mysql-connector-j-9.x.x.jar

from Downloads folder.

Click:

Apply and Close
